# Gramatika: pojmy

> Předmět: Čeština · Lekce k maturitě

## Overview
Gramatika se dělí na tvarosloví (morfologii) a skladbu (syntax). Pojmy z obou oblastí se objevují v testu.

## Pravidla
- Morfologie: slovní druhy a tvary slov (skloňování, časování).
- Syntax: věta, větné členy, souvětí.
- Morfém: nejmenší významová část slova (předpona, kořen, přípona, koncovka).
- Čeština je flektivní jazyk: vztahy vyjadřuje koncovkami.
- Shoda (mladý muž), řízenost (bát se koho), přimykání (běžet rychle).

## Kartičky
- morfologie = tvarosloví
- syntax = skladba
- morfém = nejmenší významová část slova
- shoda = mladý muž
- řízenost = bát se koho
- přimykání = běžet rychle
