# Slovesný vid

> Předmět: Čeština · Lekce k maturitě

## Overview
Vid vyjadřuje, zda je děj ukončený (dokonavý), nebo probíhající či opakovaný (nedokonavý). Dokonavá slovesa nemají přítomný čas, jejich přítomný tvar vyjadřuje budoucnost.

## Pravidla
- Nedokonavý vid: dělat, psát, kupovat. Budoucí čas: budu psát.
- Dokonavý vid: udělat, napsat, koupit. Tvar „napíšu“ = budoucí čas.
- Vidové dvojice: psát – napsat, kupovat – koupit, brát – vzít.
- Obouvidová slovesa: věnovat, jmenovat, obětovat.
- Násobená slovesa (opakovaný děj): chodívat, psávat.

## Příklady
- „Zítra to udělám.“ (dokonavé, budoucí význam)
- „Celý den jsem psal.“ (nedokonavé, probíhající děj)

## Kartičky
- dokonavý vid = ukončený děj (napsat)
- nedokonavý vid = probíhající děj (psát)
- napíšu = budoucí čas dokonavého slovesa
- obouvidové sloveso = věnovat, jmenovat
