# Psaní n/nn

> Předmět: Čeština · Lekce k maturitě

## Overview
Dvě n píšeme tam, kde se na hranici stavby slova setká n kořene s n přípony (cen-ný, kamen-ný, den-ní). Kde kořen n nemá, je jen jedno n z přípony (vod-ní, dřevě-ný).

## Pravidla
- Přídavná jména od podstatných jmen s n na konci kořene: cena → cenný, kámen → kamenný, den → denní, ráno → ranní, víno → vinný.
- Bez n v kořeni jen jedno n: voda → vodní, škola → školní, slunce → sluneční.
- Trpná příčestí a přídavná jména od sloves: jedno n (ztracený, vrozený, zakázaný).
- Podstatná jména na -nost: cenný → cennost, vinný → vinnost, ale bezcitný → bezcitnost.
- Dvojice: raný (brzký) × ranný (týkající se rány, např. ranný hnis).

## Příklady
- cenný, kamenný, denní, ranní, vinný × vodní, školní, sluneční.

## Kartičky
- cenný = cena + -ný
- ranní = od slova ráno
- raný = brzký
- ranný = týkající se rány
- vodní = jedno n, voda nemá n v kořeni
