# Sloh: pojmy

> Předmět: Čeština · Lekce k maturitě

## Overview
Slohové pojmy popisují, jak je text postaven a k čemu slouží. Každý text má slohový postup a slohový útvar.

## Pravidla
- Slohové postupy: informační (zpráva, oznámení), vyprávěcí (vypravování), popisný (popis, charakteristika), úvahový (úvaha), výkladový (výklad).
- Slohové útvary: zpráva, oznámení, dopis, žádost, životopis, referát, fejeton, úvaha, recenze, reportáž.
- Fejeton = krátký vtipný publicistický útvar. Sloupek = krátký komentář v novinách. Glosa = krátký kritický komentář.
- Kompozice textu: úvod, stať, závěr. Odstavec = myšlenkový celek.

## Kartičky
- fejeton = krátký vtipný publicistický útvar
- recenze = hodnocení díla
- úvaha = vyjádření vlastního názoru
- výklad = odborné vysvětlení
- glosa = krátký kritický komentář
