# Jazykovědné obory

> Předmět: Čeština · Lekce k maturitě

## Overview
Jazykověda (lingvistika) zkoumá jazyk z různých stránek. Každý obor má svůj předmět.

## Pravidla
- Fonetika a fonologie: zvuková stránka jazyka.
- Ortoepie: spisovná výslovnost. Ortografie: pravopis.
- Lexikologie: slovní zásoba. Lexikografie: tvorba slovníků. Etymologie: původ slov.
- Morfologie: tvarosloví. Syntax: skladba.
- Stylistika: sloh. Sémantika: význam.
- Dialektologie: nářečí. Onomastika: vlastní jména.

## Kartičky
- etymologie = původ slov
- lexikologie = slovní zásoba
- ortoepie = spisovná výslovnost
- ortografie = pravopis
- dialektologie = nářečí
- onomastika = vlastní jména
