# Skloňování zájmen

> Předmět: Čeština · Lekce k maturitě

## Overview
Zájmena mají vlastní skloňování a krátké a dlouhé tvary. Nejčastější chyby jsou mě/mně, jí/ji, ty/ti, jejich/jich.

## Pravidla
- mě = 2. a 4. pád (bez mě, vidí mě). mně = 3. a 6. pád (dej mně, o mně). Pomůcka: kde je „tobě“, je „mně“.
- ji = 4. pád (vidím ji), jí = 3. pád (dám jí) a 7. pád (s ní).
- ti = 1. p. mn. č. mužský životný (ti muži); ty = ostatní rody (ty ženy, ty stromy).
- jejich = přivlastňovací (jejich dům), jich = 2. pád od oni (je jich hodně).
- svůj × můj: ve vztahu k podmětu se používá svůj (Vzal si svou tašku).

## Příklady
- Mně se to líbí, ale mě se nikdo neptal.
- Viděl jsem ji a dal jsem jí dárek.

## Kartičky
- mně = 3. a 6. pád (jako tobě)
- mě = 2. a 4. pád (jako tebe)
- ji = 4. pád: vidím ji
- jí = 3. pád: dám jí
- jejich = přivlastňovací zájmeno
